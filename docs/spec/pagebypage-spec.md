# PageByPage 功能規格（復刻）

本文件是 eyePageFlow 的功能基準，依原作說明文件與實際畫面截圖整理，並以我們自己的文字重寫。原作程式、圖像與說明文件不直接複製。

## 1. 產品定位

- 純文字小說的閱讀器兼編輯器。
- 核心體驗是「分頁閱讀」：模擬實體書、可切換直排／橫排、快速開啟大檔案。
- 目標平台：Windows 10/11 x64、Ubuntu 24.04 x64（原生 X11）、Ubuntu 26.04 x64（原生 Wayland）。
- UI 預設繁體中文；i18n 架構保留英文／日文。

## 3. 主視窗

- 標題列：`eyePageFlow - <檔名>`；可設定是否顯示檔名。
- 選單：`文件(F)`、`編輯(E)`、`查看(V)`、`幫助(H)`。
- 工具列分組：
  1. 開啟、儲存
  2. 剪下、複製、貼上
  3. 復原、重做
  4. 顯示比例／頁面模式
  5. 顯示設定、章節列表、書籤、書庫、說明
- 閱讀區：整塊自繪，右側垂直捲軸（以頁為單位）。
- 狀態列：左側 `就緒`／`低調模式`；右側 `目前頁/總頁, 百分比`。
- 空白狀態：置中顯示 eyePageFlow logo 與 tagline；雙擊閱讀區開檔。
- 沒有 tab、沒有多視窗；單一文件。

## 4. 顯示設定

獨立視窗，左側表單、右側即時預覽；按鈕在左側面板底部（取消／確定）。對話框編輯一份設定複本，確定才套用到主視窗。

| 群組 | 欄位 | 選項／备注 |
|---|---|---|
| 頁面布局 | 顯示模式 | 自動單雙頁、單頁、雙頁、等高對稱 |
| | 顯示書本和桌面 | 取消＝低調模式，只畫頁面內容 |
| | 桌面圖案 | 純色、黑絨、深木紋、淺木紋、亞麻布、自訂圖片 |
| | 單頁模式下書籍寬度 | 像素，預設 900 |
| 封面 | 內置圖案 | 純色、棕皮革、藍布面、米紙、自訂 |
| | 顏色 | 圖案為「無」時才生效 |
| 頁面 | 內置圖案 | 純色、米紙、白紙、仿古紙、自訂 |
| | 顏色 | 圖案為「無」時才生效 |
| | 配色方案 | 預設、護眼、夜間、羊皮紙、高對比、自訂 |
| | 中縫 | 無、淺灰、米色、抹茶、深棕、自訂 |
| 文字 | 字體 | 預設 Noto Serif CJK TC，可選系統字型 |
| | 顏色 | 文字顏色 |
| | 大小 | 點數 |
| | 高度 | 相對於字號的百分比，預設 150% |
| | 加粗 | 開／關 |
| | 顯示下劃線 | 開／關 |
| | 下劃線顏色 | 顏色 |
| 翻頁 | 動畫 | 無、淡入、平移、捲頁 |

預覽使用與主視窗相同的渲染器；書本以邏輯尺寸排版後縮放到預覽區。

> M1 現況：表單已接上主題、版面、頁寬、字體家族、字級、行高、粗體、底線、五組顏色、三組內置圖案、配色方案、中縫具名預設色與動畫選項；翻頁動畫已可播放（CURL 為近似效果）。
>
> 下劃線是整頁頁面線：橫排每個行槽橫跨內容區，直排每個欄槽縱貫內容區；不是只畫在文字出現的位置。

編輯模式：空白鍵＝下一頁，Shift+空白＝插入空白；Home／End 移到行首／行尾，Ctrl+Home／Ctrl+End 移到檔案頭／尾；Del 刪除；滑鼠滾輪滾一行。

> M2 現況：編輯器使用 RSyntaxTextArea，已接上尋找／取代、dirty 標記、單頁書本外觀與 undo/redo 100 次上限。空白鍵＝下一頁、Shift+空白＝插入空白（2026-11-04 完成）；空白鍵會把游標移到下一頁起點，不切換卡片。
>
> M8 現況：章節列表支援預設／簡中／純數字／自訂正規表達式規則，會標示目前章節，支援閱讀模式跳頁與編輯模式移動游標；規則、書籤與最近開啟檔案都已持久化到 XDG／AppData。
>
> M9 現況：書庫／預設書架／檔案列表、老闆鍵與單一實例已完成。GNOME／Wayland 目前不支援 `SystemTray`，老闆鍵會退回最小化；有托盤的桌面會安裝托盤圖示。第二次啟動會把檔案送到既有視窗；檔案關聯註冊留到打包階段。

## 6. 檔案與編碼

- 主要 legacy 編碼：**Big5**（繁中）。
- 次要：GB18030／GBK（簡中）。
- Unicode：UTF-8（BOM 可選）、UTF-16LE／BE（BOM）。
- 日文編碼（Shift_JIS／EUC-JP）保留架構，v2 實作。
- 偵測順序：BOM → 合法 UTF-8 → Big5 → GB18030 → 使用者指定。
- 存檔保持原編碼、BOM、換行格式；不悄悄改變。
- 原編碼無法表示某字時，**每次詢問**，預設另存 UTF-8；另提供 UTF-16LE 與取消。
- 新檔預設 UTF-8（可設定 BOM 與 CRLF）。
- 巨型檔案：10 MiB 內秒開；20 MiB 可接受。M0 量測見 handoff。

## 7. 設定與資料存放

- Linux：`$XDG_CONFIG_HOME/eyePageFlow/`、`$XDG_DATA_HOME/eyePageFlow/`。
- Windows：`%APPDATA%\eyePageFlow\`。
- 設定：`settings.properties`（或 JSON；M1 定案）。
- 書籤、章節關鍵字、書庫：獨立檔案，可選匯入原作 `.bmk`／`.chp`／`.blb`。
- 不把使用者資料寫在執行檔旁。

## 8. 與原作差異

| 項目 | 原作 | eyePageFlow |
|---|---|---|
| Legacy 編碼 | ANSI（實務上 GBK） | Big5 為主，GB18030 為輔 |
| 無法表示的字 | 自動轉 UTF-16 | 詢問，預設 UTF-8 |
| Unicode 範圍 | 僅 BMP | 完整 Unicode（含 supplementary） |
| 語言 | 僅簡中 | 繁中 UI，i18n 保留英／日 |
| 章節上限 | 4096 項 × 30 字 | 不設硬上限，仍可設定效能上限 |
| 圖像素材 | 原作內建圖片 | 自製程序化材質／自有素材 |
| 平台 | Windows only | Windows／Ubuntu 24.04 X11／26.04 Wayland |
| 資料位置 | 執行檔旁 INI | XDG／AppData |

## 9. 驗收條件（M0／M1）

- 10 MiB Big5 檔：解碼＋分頁 < 1 秒（M0 已達標，見 handoff）。
- 直排與橫排頁數不同；切換模式後保留字元位置。
- 直排：頁 1 在右、頁 2 在左；橫排相反。
- 狀態列百分比＝`目前頁/總頁×100`，兩位小數。
- Ubuntu 26.04 原生 Wayland 使用 `WLToolkit` 啟動；XWayland fallback 可啟動。
- Ubuntu 24.04 原生 X11 使用 `XToolkit` 啟動（待驗證）。
- 顯示設定預覽與主視窗使用同一渲染器。
