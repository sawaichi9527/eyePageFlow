# 主題與素材規格

## 1. 主題模型

一個主題就是一組顯示設定的 preset：

```text
桌面：顏色 + 材質
封面：顏色 + 材質
頁面：顏色 + 材質
文字：顏色
中縫：顏色
陰影 / 頁碼：顏色
```

使用者改任一欄位後，主題自動變成「自訂」。

## 3. 程序化材質

M0 不內建照片素材，先用 Java2D 產生 deterministic 材質：

- `WOOD`：深色底 + 水平木紋線。
- `LEATHER`：底色 + 細點噪聲 + 內框。
- `PAPER`：米色底 + 細橫線 + 少量斑點。
- `LINEN`：細直線／橫線交織。
- `NONE`：純色。

同一材質使用固定 seed，避免每次重繪閃爍。之後若換成圖片素材，介面與 manifest 不變。

## 4. 素材 manifest（M1 建立）

每個內建圖案需要：

```text
id            例如 desktop.wood.dark
displayName   例如 深木紋
kind          desktop / cover / page / gutter / scheme
thumbnail     選單縮圖
source        自製 / CC0 / OFL / 授權說明
```

規則：

- 不直接複製原作 logo、封面圖、桌面圖、頁面圖、工具列圖示。
- 圖片素材需記錄來源與授權，列入 `THIRD_PARTY_NOTICES.md`。
- 預設主題必須在沒有網路、沒有額外素材的情況下可用。

## 5. 設定優先順序

1. 圖案不是「無」→ 使用圖案，顏色鈕停用。
2. 圖案為「無」→ 使用顏色。
3. 配色方案一次設定頁面顏色與文字顏色；手動改色後變成「自訂」。
4. 頁面圖案不影響文字顏色。
5. 下劃線顏色獨立於文字顏色，預設跟隨文字顏色；開啟下劃線時是整頁頁面線。
6. 低調模式（取消「顯示書本和桌面」）只畫頁面內容，不畫桌面、封面、陰影、中縫。

## 6. 顯示設定中的主題入口

在顯示設定左側最上方加一個「主題」下拉：

- 仿真紙書
- 現代簡約
- 自訂

切換主題時，一次套用桌面／封面／頁面／中縫／配色；使用者在任何欄位手動修改後，下拉自動切到「自訂」。
