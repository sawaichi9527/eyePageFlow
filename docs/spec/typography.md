# 排版規格

本文件定義 eyePageFlow 的頁面幾何、直排／橫排規則、頁序、頁碼與狀態列。數值以 M0 原型為基準，之後由顯示設定覆寫。

## 1. 邏輯頁面

| 項目 | 預設值 |
|---|---|
| 單頁寬 | 900 px |
| 頁高 | 850 px |
| 上／下邊界 | 42 / 58 px |
| 左／右邊界 | 44 / 44 px |
| 內容區 | 812 × 750 px |
| 字號 | 24 pt |
| 行高 | 150% |
| 直排欄距 | 字號 × 1.2 |
| 段落縮排 | 2 字 |

書本在視窗中置中；桌面填滿書本以外的區域。

- 單頁模式：書本寬 = 900 px。
- 雙頁模式：書本寬 = 2 × 900 + 中縫（10 px）。
- 書本高 = 頁高；依視窗可用空間等比縮放。
- 封面比頁面外擴約 14 px（依縮放比例）。

## 2. 頁序與頁碼

| 模式 | 第一頁 | 第二頁 | 閱讀方向 |
|---|---|---|---|
| 直排 | 右頁 | 左頁 | 右→左 |
| 橫排 | 左頁 | 右頁 | 左→右 |

- 一個 spread 固定兩頁：`(1,2)`、`(3,4)`、`(5,6)`……
- 頁碼畫在頁面**外側下角**，永遠正立：
  - 左頁：左下角。
  - 右頁：右下角。
  - 單頁：底部置中。
- 頁碼是頁面渲染的一部分，不是狀態列文字。

## 3. 狀態列

格式：

```text
目前頁/總頁, 百分比
```

百分比 = `目前頁 / 總頁 × 100`，四捨五入到小數第二位。

實例：

- `1/849, 0.12%`（1 ÷ 849 × 100）
- `1/876, 0.11%`（1 ÷ 876 × 100）

注意不是 `(目前頁-1)/總頁`；第一頁不是 0.00%。

## 4. 橫排規則

- 文字由左至右、由上至下。
- 行高 = 字號 × 高度百分比（預設 150%）。
- 行寬 = 內容區寬；超出時換行。
- 段落第一行縮排 2 字；寬度造成的自動換行不縮排。
- 換行時優先避免行首標點（`。、，．：；！？）」』】》`）與行尾開括號（`（「『【《`）。M0 尚未完整實作，列為 M3 驗收項。
- 左右對齊（justify）為目標行為；M0 尚未實作。
- 下劃線是**整頁頁面線**，不是逐字底線：每個行槽從內容區左緣畫到右緣，短行與空白行也會有線，讓頁面像橫線紙。顏色使用「下劃線顏色」設定。
- 拉丁字母與數字保持正立。

## 5. 直排規則

- 文字由上至下、欄位由右至左。
- 每字佔一個正方形 cell：cell 高 = 字號，欄距 = 字號 × 1.2。
- 第一欄從內容區最右側開始，往左排列。
- 段落第一欄頂端縮排 2 格；自動換欄不縮排。
- 標點使用 Unicode 直排形式（若字型支援）：
  - `。`→`︒`、`、`→`︑`、`，`→`︐`
  - `：`→`︓`、`；`→`︔`、`！`→`︕`、`？`→`︖`
  - `「`→`﹁`、`」`→`﹂`、`『`→`﹃`、`』`→`﹄`
  - `（`→`︵`、`）`→`︶`、`《`→`︹`、`》`→`︺`、`〈`→`︷`、`〉`→`︸`
  - `…`→`︙`、`—`→`︱`
- 字型不支援直排形式時，退回「原字形旋轉或位移」的近似法，並記錄 warning。
- 拉丁字母與數字順時針旋轉 90°；CJK 保持正立。
- 下劃線是**整頁頁面線**：每個欄槽從內容區上緣畫到下緣，短欄與空白欄也會有線；線在欄位右側。顏色使用「下劃線顏色」設定。
- 直排時滑鼠點擊方向反轉：點左半區往後翻、點右半區往前翻。

## 6. 模式切換與位置保存

- 位置一律以**字元 offset** 表示，不用頁碼。
- 切換直排／橫排、改變字型或字級、改變頁面尺寸時：
  1. 記下目前 spread 第一頁的 `startOffset`。
  2. 重新分頁。
  3. 找到包含該 offset 的頁。
  4. 對齊到偶數頁（雙頁 spread 起點）。
- 目標：切換後第一個可見字元不變；頁碼與總頁數可以改變。

## 7. 字型與量測

- 預設字型：Noto Serif CJK TC（OFL），內嵌於安裝檔。
- 允許切換系統字型；切換後重新分頁。
- 字寬表：以 `(字型檔 hash, 字級, 粗體)` 為 key 快取到 XDG cache。
- 分頁只做字寬查表與換行計算，不逐頁建立 DOM／元件。
- 頁面內容只在實際繪製時組字。

## 8. M0 原型現況

已完成：

- 橫排與直排分頁、頁序、頁碼、狀態列。
- 段落縮排（水平行首／直排欄頂）。
- 直排 Unicode 形式標點與拉丁字母旋轉。
- 10 MiB Big5 分頁 < 1 秒。

尚未完成（M3／M4／M5 驗收）：

- 完整禁則處理（行首／行尾標點）。
- 左右對齊。
- 直排標點的精確位置與字型 fallback 警告。
- surrogate pair（emoji、罕用字）逐字處理。
- 標點擠壓、行距微調、頁面底部孤行控制。
- 真正的「單頁／雙頁／等高對稱」三種尺寸模式。
