# 排版規格

本文件定義 eyePageFlow 的頁面幾何、直排／橫排規則、頁序、頁碼與狀態列。數值以 M0 原型為基準，之後由顯示設定覆寫。

## 1. 邏輯頁面

| 項目 | 預設值 |
|---|---|
| 單頁寬 | 900 px |
| 頁高 | 920 px |
| 上／下邊界 | 32 / 32 px |
| 左／右邊界 | 44 / 44 px |
| 內容區 | 812 × 856 px |
| 字號 | 26 pt |
| 行高 | 144% |
| 直排欄距 | 字號 × 1.5 |
| 段落縮排 | 2 字 |

以上數值對齊原作 PageByPage 的實測比例（原作頁面 909 × 919、內容區 825 × 872、
字距 26 px、欄距與行距皆為 39 px）。

書本在視窗中置中；桌面填滿書本以外的區域。

- 單頁模式：書本寬 = 900 px。
- 雙頁模式：書本寬 = 2 × 900 + 中縫（10 px）。
- 書本高 = 頁高；依視窗可用空間等比縮放。
- 封面比頁面外擴約 14 px（依縮放比例）。

## 2. 頁序與頁碼

| 模式 | 第一頁 | 第二頁 | 閱讀方向 |
|---|---|---|---|
| 直排 | 右頁 | 左頁 | 右→左 |
| 橫排 | 左頁 | 右頁 | 左→右 |

- 一個 spread 固定兩頁：`(1,2)`、`(3,4)`、`(5,6)`……
- 頁碼畫在頁面**外側下角**，永遠正立：
  - 左頁：左下角。
  - 右頁：右下角。
  - 單頁：底部置中。
- 頁碼是頁面渲染的一部分，不是狀態列文字。

## 3. 狀態列

格式：

```text
目前頁/總頁, 百分比
```

百分比 = `目前頁 / 總頁 × 100`，四捨五入到小數第二位。

實例：

- `1/849, 0.12%`（1 ÷ 849 × 100）
- `1/876, 0.11%`（1 ÷ 876 × 100）

注意不是 `(目前頁-1)/總頁`；第一頁不是 0.00%。

## 4. 橫排規則

- 文字由左至右、由上至下。
- 行高 = 字號 × 高度百分比（預設 144%）。
- 行寬 = 內容區寬；超出時換行。
- 段落第一行縮排 2 字；寬度造成的自動換行不縮排。
- 標點擠壓：
  - 連續標點（`。、，．：；！？…`）的第二個以後只佔半個字寬，橫排壓右半、直排壓下半；
    墨跡靠右的 `」』）` 不列入，避免壓縮後撞字。
  - 行尾／欄尾懸掛：關閉類標點只差半個字就能放下時，允許掛在內容區邊緣外，不多換一行；
    但如果後面還接著其他標點就不懸掛（否則整串會有一個被擠到行首）。
  - 行首／欄首擠壓：真的遇到行首標點（例如緊接換行）時壓成半個字寬，不整串推到下一行。
- 禁則：換行時避免行首出現 `。、，．：；！？）」』】》〉…`，也避免行尾留下 `（「『【《〈`；
  連續的關閉標點會整段帶到下一個行。
- 行距微調：一頁可放的行數不變，把 `contentHeight - 行數 × 行距` 的剩餘高度平均分配給各行，
  讓最後一行貼近下緣；最多放寬 5%，頁與頁間距一致（只跟版面參數有關）。頁面下劃線用同一組間距。
- 左右對齊（justify）：因寬度換行的行會把剩餘寬度平均分配到字距，讓行尾貼齊內容區右緣；
  段末行不拉齊，剩餘寬度超過 0.5 字時也不硬拉（避免字距過鬆）。可在顯示設定關閉。
- 下劃線是**整頁頁面線**，不是逐字底線：每個行槽從內容區左緣畫到右緣，短行與空白行也會有線，讓頁面像橫線紙。顏色使用「下劃線顏色」設定。
- 拉丁字母與數字保持正立。

## 5. 直排規則

- 文字由上至下、欄位由右至左。
- 每字佔一個正方形 cell：cell 高 = 字號，欄距 = 字號 × 1.5。
- 半角字（拉丁字母、數字、半角標點）旋倒後依字寬前進，下限 0.5em：
  讓 `eyePageFlow`、`UTF-8` 這類字串保持字距。下限不能再低（0.3em 時
  `1`、`.` 的旋倒墨跡會比字格高，壓到前後的字）。
- 直排時每個字的「行框」在字格內垂直置中。字格高度 = 字號，但字型的
  ascent + descent 通常更大（Noto Serif CJK 26px 是 38px），沿用基線會讓墨跡
  往下溢 6px；`第10段` 的數字被 `第` 壓住就是這個原因。
- 第一欄從內容區最右側開始，往左排列。
- 段落第一欄頂端縮排 2 格；自動換欄不縮排。
- 標點使用 Unicode 直排形式（若字型支援）：
  - `。`→`︒`、`、`→`︑`、`，`→`︐`
  - `：`→`︓`、`；`→`︔`、`！`→`︕`、`？`→`︖`
  - `「`→`﹁`、`」`→`﹂`、`『`→`﹃`、`』`→`﹄`
  - `（`→`︵`、`）`→`︶`、`《`→`︹`、`》`→`︺`、`〈`→`︷`、`〉`→`︸`
  - `…`→`︙`、`—`→`︱`
- 字型不支援直排形式時：CJK 標點（`。、，：；`）依「直排標點」設定擺放——
  「置中」（預設）沿用原字形，墨水在字格內自然置中；
  「右上」（標準中文直排）依字形視覺邊界換算位移，把墨跡放到字格右上角。
  拉丁字母、括號與刪節號改用旋轉 90° 的近似法。
- 拉丁字母與數字順時針旋轉 90°；CJK 保持正立。
- 下劃線是**整頁頁面線**：每個欄槽從內容區上緣畫到下緣，短欄與空白欄也會有線；線在欄位右側。
  顏色使用「下劃線顏色」設定；粗細為三選一：淡（0.5 px，預設）、普通（1.0 px）、粗黑（1.5 px）。
- 直排時滑鼠點擊方向反轉：點左半區往後翻、點右半區往前翻。

## 6. 模式切換與位置保存

- 位置一律以**字元 offset** 表示，不用頁碼。
- 切換直排／橫排、改變字型或字級、改變頁面尺寸時：
  1. 記下目前 spread 第一頁的 `startOffset`。
  2. 重新分頁。
  3. 找到包含該 offset 的頁。
  4. 對齊到偶數頁（雙頁 spread 起點）。
- 目標：切換後第一個可見字元不變；頁碼與總頁數可以改變。

## 7. 字型與量測

- 預設字型：Noto Serif CJK TC（OFL），內嵌於安裝檔。
- 允許切換系統字型；切換後重新分頁。
- 字寬表：以 `(字型檔 hash, 字級, 粗體)` 為 key 快取到 XDG cache。
- 分頁只做字寬查表與換行計算，不逐頁建立 DOM／元件。
- 頁面內容只在實際繪製時組字。

## 8. M0 原型現況

已完成：

- 橫排與直排分頁、頁序、頁碼、狀態列。- 段落縮排（水平行首／直排欄頂）。
- 直排 Unicode 形式標點與拉丁字母旋轉。
- 禁則：關閉標點（`。、，！？）」』】》〉…`）不落在行首／欄首，
  開括號（`（「『【《〈`）不落在行尾／欄尾；連續關閉標點會整段帶到下一個行／欄。
- 橫排左右對齊（justify），段末行與過鬆的行不拉齊。
- Surrogate pair（emoji）視為單一字、佔一格，頁面邊界不會切在代理對中間；
  頁面字型缺字時退回系統 emoji 字型。
- 10 MiB Big5 分頁 < 1 秒。

尚未完成（M3／M4／M5 驗收）：

- 直排的「字距微調」（目前直排仍固定 1em 字格，未做垂直方向的平均分配）。
- 直排標點的精確位置與字型 fallback 警告。
- 直排的「字距微調」（目前直排仍固定 1em 字格，未做垂直方向的平均分配）。
- 真正的「單頁／雙頁／等高對稱」三種尺寸模式。
